1. Forms: MetaText Compound Field

Packs UHID, Triage, Editable Patient Name, Age (red font alert), and Sex into one 40px form slot.

Compound Form Input
UHID: 1221 TRIAGE: LEVEL 2
Pt -
AGE: 45 YRS SEX: Male

⚡ Exact same 40px height as a standard textbox; stores 4 linked clinical attributes.

Code Sample Go DSL & Declarative HTML 
// Go DSL (One-line Shorthand with !red color modifier)
components.MetaTextField("UHID: 1221, TRIAGE: LEVEL 2 | [@pt_name: David Jeba] | AGE: 45!red, SEX: Male")

<!-- Declarative HTML Component -->
<div class="hs-metatext inline-flex flex-col justify-between h-10 w-full rounded border border-slate-300 bg-white">
  <div class="grid grid-cols-2 divide-x border-b text-[8px] font-mono uppercase px-2 h-[11px] items-center leading-none bg-slate-50">
    <span>UHID: 1221</span>
    <span class="text-right text-amber-600 font-bold">TRIAGE: LEVEL 2</span>
  </div>
  <div class="px-2 flex items-center h-[18px] bg-white leading-none">
    <span class="text-sm font-bold text-slate-400 mr-1">Pt -</span>
    <input type="text" name="pt_name" value="David Jeba" class="text-sm font-bold text-slate-950 bg-transparent border-0 p-0 m-0 leading-none focus:outline-none" />
  </div>
  <div class="grid grid-cols-2 divide-x border-t text-[8px] font-mono uppercase px-2 h-[11px] items-center leading-none bg-slate-50">
    <span>AGE: <strong class="text-red-600 font-bold">45</strong></span>
    <span class="pl-1">SEX: <strong class="text-slate-900">Male</strong></span>
  </div>
</div>
