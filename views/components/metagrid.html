MetaGrid (<meta-grid>)

The second Hyperstack Meta Component—an enterprise upgrade of <hx-grid>. Controlled declaratively by metagrid.fx, it provides two official views: metagrid (integrated table browser + formula bar + sheet) and metagrid-ext (2-tier parent totals → child breakups). Disable interactive flags in .fx and it degrades cleanly to a simple static table.

1. Configuring via metagrid.fx

Every pane, scrollbar, pagination strategy (numbers, vscroll, hscroll), and interactive capability is governed by .fx. Turning off keyboard, editable, and formulaBar degrades the grid to a zero-listener static table. 

{
  "id": "ledgerMetaGrid",
  "mode": "metagrid-ext",
  "features": {
    "keyboard": true,
    "editable": true,
    "formulaBar": false
  },
  "pane1": { "src": "/api/summary", "pagination": "numbers", "pageSize": 25, "scrollbars": "y" },
  "pane2": { "src": "/api/dept-breakup", "scrollbars": "y" },
  "pane3": { "src": "/api/ledger-details", "pagination": "hscroll", "scrollbars": "both" }
}

2. Go DSL 1:1 Parity (go/components/metagrid.go)

Or compose two standalone <hx-grid> elements listening to hx-grid:select for custom parent–child workflows. 

components.MetaGrid(components.MetaGridProps{
    ID:    "pmGrid",
    Mode:  "metagrid",
    Title: "Master Content Authoring",
    Features: &components.MetaGridFeatures{
        Keyboard: true, Editable: true, FormulaBar: true,
    },
    Pages: []components.MetaGridPage{
        {ID: "pm", Label: "Purchase Masters", Code: "PM", Src: "/api/pages/pm"},
    },
    Pane1: components.MetaGridPane{
        Pagination: "numbers", PageSize: 25, Scrollbars: "auto",
    },
})
