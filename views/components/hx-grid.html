Enterprise Data Grid (<hx-grid>)

A high-performance virtualized data grid built for complex ERP applications. Supports 100k+ rows at 60fps, column resizing, multi-row selection, inline cell editing, and client-side CSV export.

Double-click any cell to edit • Drag column borders to resize

Declarative HTML Usage

<!-- 1. Include the Grid engine -->
<script src="/htmx-grid.js"></script>

<!-- 2. Declarative 100k-row Grid bound to JSON API -->
<div hx-grid 
     hx-grid-src="/api/invoices.json" 
     hx-grid-row-height="40">
</div>

<!-- 3. Component Registry (Flyweight Pattern) & Server Directives -->
<script>
  const grid = new HxGrid.EnterpriseDataGrid(document.getElementById('my-grid'), {
    rowHeight: 40, // Exact 40px flush match: The Component IS the Cell
    columns: [
      { field: 'id', header: 'ID', compid: 'text', width: 90 },
      
      // Compound MetaText (2x2 + Hero, zero nested gap)
      { field: 'client', header: 'Client & Account', compid: 'metatext', width: 280 },
      
      // Chips with Server-Pushed Directives (Single vs Multi select)
      { 
        field: 'tags', 
        header: 'Acuity Tags', 
        compid: 'chipsui', 
        width: 180,
        directives: { mode: 'single', maxTags: 1 } // 0ms local radio enforcement!
      },
      
      // Flush Status Dropdown
      { field: 'status', header: 'Status', compid: 'dropdown', width: 140 },
      
      { field: 'date', header: 'Due Date', compid: 'date', width: 110 }
    ],
    data: myInvoiceData // Raw primitive arrays/tuples (Zero HTML overhead across 1M rows!)
  });

  // Hot-push server directives dynamically without page reload:
  grid.applyDirectives('tags', { mode: 'multi', maxTags: 5 });
</script>

How 1,000,000-Row Zero-Lag Virtualization Works

  • The Component IS the Cell: Zero cell padding or margin (p-0 m-0 h-10). The element touches the gridlines flush.
  • Flyweight DOM Recycling: The grid creates a fixed pool of only ~30 visible row elements. Scrolling at 120fps triggers zero DOM node allocations.
  • Server-Pushed Directives: The server pushes behavioral constraints (mode: "single") down via the schema. The client executes them in 0.0ms with zero HTTP round-trips.
  • Zero-Markup Wire Payload: The server sends raw primitive tuples instead of 500MB of repetitive HTML tags.
